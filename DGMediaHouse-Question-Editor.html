Marketing Audit Customization

วิธีใช้งาน — กดปุ่มเดียว

  1. แก้ ข้อความหน้าแรก (Landing) ได้ในการ์ดด้านล่าง — เปลี่ยนหัวข้อ / คำอธิบาย / Stats / ปุ่ม CTA ได้ทั้งหมด
  2. แก้ คำถาม / ตัวเลือก / คะแนน ได้ในการ์ดถัดไป (เปลี่ยนแล้วเปลี่ยนเลย)
  3. เพิ่ม / ลบ / สลับลำดับคำถามด้วยปุ่มมุมขวาบนของแต่ละข้อ
  4. กรอก Webhook URL ที่ด้านล่าง (Optional) ถ้าอยากให้ไฟล์ใหม่ส่ง Lead ไป Google Sheets กลางของบริษัท
  5. กด ⤴ Download HTML → ได้ไฟล์ Audit ใหม่ทันที (ไม่ต้องอัปโหลดอะไร)
  6. ไฟล์ใหม่อยู่ที่ Downloads → ลากไปทับไฟล์เดิมในโฟลเดอร์ Megnet แล้ว Deploy ตามวิธีเดิม

คัดลอก JavaScript Code

คัดลอกโค้ดด้านล่าง — มี 2 บล็อก: const landingContent = {...} (หน้าแรก) และ const questions = [...] (คำถาม) ในไฟล์ DGMediaHouse-Marketing-Audit.html

  1. เปิดไฟล์ DGMediaHouse-Marketing-Audit.html ด้วยโปรแกรมแก้ข้อความ
  2. หาบล็อก const landingContent = { → ลบจนถึง }; แล้ววางบล็อกแรกที่ copy ลงไปแทน
  3. หาบล็อก const questions = [ → ลบจนถึง ]; แล้ววางบล็อกที่สองลงไปแทน
  4. Save ไฟล์ — เสร็จเรียบร้อย (แนะนำให้ใช้ปุ่ม ⤴ Download HTML จะง่ายกว่า)
