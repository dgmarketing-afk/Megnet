วิธีใช้งาน — กดปุ่มเดียว

  1. แก้คำถาม / คำอธิบาย / ตัวเลือก / คะแนนได้ตามต้องการ (เปลี่ยนแล้วเปลี่ยนเลย)
  2. เพิ่ม / ลบ / สลับลำดับคำถามด้วยปุ่มมุมขวาบนของแต่ละข้อ
  3. กรอก Webhook URL ที่ด้านล่าง (Optional) ถ้าอยากให้ไฟล์ใหม่ส่ง Lead ไป Google Sheets ของคุณ
  4. กด ⤴ Download HTML → ได้ไฟล์ Audit ใหม่ทันที (ไม่ต้องอัปโหลดอะไร)
  5. ไฟล์ใหม่อยู่ที่ Downloads → ลากไปทับไฟล์เดิมในโฟลเดอร์ Megnet
